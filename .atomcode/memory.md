- uni-halo-plugin 前端约定：页面/组件内部 import 优先用 @ 别名（@/api、@/types、@/components/...），不用相对路径；@ 指向 ui/src。
- uni-halo-plugin CI/CD packages 构建方案（已讨论待实施）：packages/float-mini-profile 不在 Gradle 构建链（settings.gradle 未 include），官方 CI 只跑 ./gradlew clean build 不会构建它，目前靠已提交的静态产物 float-mini-profile.js 兜底（有忘构建发旧版风险）。实施方案：1) settings.gradle include 'packages/float-mini-profile'；2) 新建 packages/float-mini-profile/build.gradle 复刻 ui/build.gradle（base + com.github.node-gradle.node 7.1.0 + PnpmTask pnpmBuild/pnpmInstall，assemble 依赖 pnpmBuild）；3) 根 build.gradle processUiResources/classes 追加 dependsOn 该子工程任务，vite 的 copyToStatic 插件自动拷产物到 src/main/resources/static/floating-window/。官方 reusable-workflows 无多 pnpm 工程支持（build-args/ui-path 均帮不上），不推荐放弃官方 workflow 自写 CI。lockfile 缓存仅覆盖 ui-path 一份，可忽略。
